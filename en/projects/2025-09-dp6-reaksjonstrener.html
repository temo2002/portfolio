DP6 Reaction trainer

Reaction game with buttons and LEDs, built as a real-time system with FreeRTOS and increasing difficulty.

  • FreeRTOS
  • interrupts
  • real time

How it works

  • Tasks for LED control, game logic and display run in parallel, and the buttons are read through interrupts.
  • The reaction window shrinks and more LEDs light up at once the better the player does.
  • All functional tests (correct press, wrong press, timeout and increased difficulty) gave the expected result.
