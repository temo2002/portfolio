DP7 Test bench for cable communication

Test bench that models a cable between two buildings and measures bit error rate and packet loss in UART communication.

  • UART
  • bit error rate
  • SNR
  • AVR

Problem statement

How is the bit error rate in cable-based UART communication affected by baud rate and signal-to-noise ratio? Since the cable did not exist yet, a test bench was built that models attenuation and noise.

Scope

  • Channel model for attenuation and noise, with bit error rate and packet loss as targets.
  • Own driver and test program in C for the microcontroller.
